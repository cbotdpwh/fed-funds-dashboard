    How requests are grouped

    • Each request belongs to exactly one type.
    • Oplan Kontra Baha (OKB): the request's remarks mention Oplan Kontra Baha or OKB, whatever its fund type.
    • Dredging by administration: all other requests with fund types that pay to run the equipment with DPWH's own crew (Operational, Labor, OSH, Bunkhouse, Office Supplies).
    • Preventive, corrective, dry docking and repair, accessories and mobilization follow the Fund Type column.
